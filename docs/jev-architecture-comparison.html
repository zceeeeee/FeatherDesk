1. 沉重的大模型税

即使页面已经展示了搜索结果，系统依然必须抓取 150 个节点的完整 ARIA 树送入大模型，耗费 3~5 秒仅为了确认一句“任务已完成”。

2. 盲目执行与反馈真空

点击按钮后 Playwright 返回成功，但现代 SPA 经常因为前端事件冒泡失效导致实际上没有任何反应。系统没有任何本地校验手段。

3. 异常排查极度迟钝

遇到假死时，系统需要整整跑满 3 轮大模型循环（耗时 15 秒以上）才会触发熔断报错，用户体验极为拖沓。

改进后流程：Jev System 1 双闭环极速自愈架构

模式 A（前置拦截）+ LLM（复杂定位）+ 模式 B（后置验证），快慢结合，职责明确。

⚡ 模式 A 的价值：阻断无意义慢思考

在搜索结果呈现、页面到达终态、或者遇到全屏扫码弹窗时，Jev 凭借单次 150ms 的分类与布尔判断直接分流。只有真正需要“从 50 个按钮里挑出具体点哪一个”时，才唤醒 GPT-4o。大模型调用频次立减 50% 以上。

🛡️ 模式 B 的价值：毫秒级防假死自愈

Playwright 经常遇到“点了但页面没反应”的假死情况。传统方式需要等下一轮花 4 秒重新扫描全树由大模型识别，而模式 B 在 350ms 内即可确认假死并直接执行坐标级物理强击（Micro-Heal），让自动化流程丝滑流畅。

代码落地点与核心接口实现设计

方案最大程度保持现有项目结构稳定，通过新增单一轻量服务模块 src/core/fast_gate.py，在现有循环的关键锚点插入无侵入拦截。

src/core/fast_gate.py (新增模块: JevFastGate 核心实现) Python 3.11+ 
from __future__ import annotations
import os
from typesafe_sdk import Choice, Noul, TypeSafeClient

class JevFastGate:
    """Jev System 1 极速门禁：前置旁路跳过 (Mode A) 与 后置动作校验 (Mode B)"""

    def __init__(self, api_key: str | None = None):
        self.client = TypeSafeClient(api_key=api_key or os.getenv("TYPESAFE_API_KEY"))
        self.enabled = os.getenv("ENABLE_JEV_GATE", "true").lower() == "true"

    def evaluate_pre_gate(self, task: str, url: str, page_text: str) -> dict:
        """模式 A: 在呼叫慢思考大模型前，毫秒级判定任务是否已搞定或被阻断"""
        if not self.enabled:
            return {"status": "need_interaction", "is_complete": False}

        state = {
            "task_objective": task,
            "current_url": url,
            "visible_text_snippet": page_text[:600]
        }

        resp = self.client.system_one(
            state=state,
            model="jev-latest",
            questions={
                "macro_status": Choice(
                    instructions="Based on the page snippet and the user's task goal, what is the current situation?",
                    criteria={
                        "goal_satisfied": "The desired information or final success state is already fully visible on the screen.",
                        "need_interaction": "The page requires interacting with inputs, buttons, or links to proceed.",
                        "blocked_by_overlay": "A login modal, captcha, or cookie consent is blocking normal view.",
                    }
                ),
                "is_goal_complete": Noul(
                    instructions="Is the user's objective completely fulfilled by the current visible content?"
                )
            }
        )
        return {
            "status": resp.answers["macro_status"].choice,
            "confidence": resp.answers["macro_status"].confidence,
            "is_complete": resp.answers["is_goal_complete"].noul >= 0.85
        }

    def verify_action_effect(self, action_name: str, delta: dict) -> dict:
        """模式 B: 动作执行后，毫秒级对比前后微差量，识别假死或报错"""
        if not self.enabled:
            return {"outcome": "navigated_successfully", "retry": False}

        resp = self.client.system_one(
            state={
                "action_executed": action_name,
                "url_before": delta.get("url_before"),
                "url_after": delta.get("url_after"),
                "new_alerts": delta.get("new_alerts", [])
            },
            model="jev-latest",
            questions={
                "action_outcome": Choice(
                    instructions="Evaluate the immediate outcome of the action based on the state delta.",
                    criteria={
                        "navigated_successfully": "The page URL changed or new view loaded as expected.",
                        "validation_failed": "Form validation failed, or an error alert/toast appeared.",
                        "inert_click": "URL did not change and no alert appeared; the click might have missed or had no listener.",
                    }
                ),
                "should_micro_retry": Noul(
                    instructions="Did the action completely fail to produce any change, indicating an inert click?"
                )
            }
        )
        return {
            "outcome": resp.answers["action_outcome"].choice,
            "should_micro_retry": resp.answers["should_micro_retry"].noul >= 0.8
        }
